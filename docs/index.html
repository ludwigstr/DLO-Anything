Summary

DLO-Anything forecasts the motion of cables (deformable linear objects) that touch each other and the floor. The test scene is simulated in MuJoCo: a robot gripper pulls one cable across a second cable that hangs as a fixed "U"; each cable has 40 segments. A physics transformer with about 5.2 M parameters, one model per cable and conditioned on the material parameters of its cable, predicts the next 20 ms; a forecast is a rollout of this single step. The models are trained on 24,000 simulated scenes and validated on robot motions of kinds that never occur in training. This is work in progress: the model and the results are still changing.

Method

One-step forecast. Each cable has its own transformer. From the last states of its cable, the material parameters and the next step of the gripper, the model predicts the cable 20 ms later. The prediction is fed back as the new state, so a 6-s forecast consists of 300 such steps and uses the simulation only for its 0.2 s of starting context.

Contact tokens. Before every step, each cable node receives two additional tokens:

  • a soft-contact token that describes the closest point on the other cable, and
  • a rigid-contact token that describes the floor patch below the node.

Both are rebuilt from the predicted state, not from the simulation. The model therefore reacts to the contact that its own forecast produces.

  • 41node tokens
  • 6material tokens
  • 1action token
  • 41soft-contact tokens
  • 41rigid-contact tokens
  • 1global token

Training data. 24,000 simulated scenes in which the gripper crosses the U on straight, angled, arc, S-curve and there-and-back paths or follows random waypoints. Scenes in which the pulled cable wraps around the U are excluded.

Metric. Mean node position error of a 6-s forecast started from 0.2 s of simulated context.

Validation on unseen robot motions

The validation set contains three kinds of robot motion that are never used for training: circles, sine oscillations and jerky start-stop motions (303 scenes; a separate test set has 341 scenes). The trainer aborts if a training file contains scenes of these kinds. The five videos below are scenes from this validation set.

The videos in this version were rendered with the 0.5-s-per-pass model variant. They will be replaced by videos of the one-step model.
